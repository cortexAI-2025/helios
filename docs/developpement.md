# Environnement de développement

## Prérequis

- Node.js ≥ 20
- npm

## Commandes

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Tests

Des tests unitaires de base sur les calculs d’orbite sont présents (`src/__tests__/engine.test.ts`) et ont été exécutés avec Vitest (2 tests passés).

## Publication

Le dépôt cible est `cortexAI-2025/helios`. Les sources sont poussées sur une branche dédiée.
